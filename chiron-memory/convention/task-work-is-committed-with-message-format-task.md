Task work is committed with message format `task(<taskId>): <description>` on the task's own branch (e.g. `task(3nLwIYtCR2nntrkYdMra): Historial de movimientos por producto (API + UI)`).

## Why
ties each commit back to its Chiron board task for traceability.

## Where
git commit workflow when finishing a board task.
